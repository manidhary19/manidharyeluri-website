# Production hosting

The portfolio is hosted entirely on GitHub Pages at https://manidharyeluri.com.
The publishing repository is https://github.com/manidhary19/manidharyeluri-website.

Push changes to its `main` branch to run `.github/workflows/pages.yml`. The
workflow installs dependencies, runs `npm run build`, and publishes `dist`.
In repository Settings → Pages, the publishing source must be **GitHub Actions**.
Do not publish the raw repository root: it contains uncompiled React source.

`scripts/build-pages.mjs` creates entry documents for all 15 routes, allowing
direct links and refreshes without server rewrites. The custom domain serves
the site at `/`, matching the application's asset and navigation URLs.

Namecheap BasicDNS records:

| Type | Host | Value |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | manidhary19.github.io |

Set the Pages custom domain to `manidharyeluri.com` and enable Enforce HTTPS
once GitHub finishes issuing its certificate. `public/CNAME` is included in
the build for consistency. No Python runtime is required: the contour data
generated by the optional Python script is already committed.

To check the live routes and assets:

```sh
SITE_URL=https://manidharyeluri.com npm run check
```
